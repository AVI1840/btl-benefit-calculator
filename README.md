# מחשבון תט״ר לנפגעי פעולות איבה

מחשבון תגמול תלוי רווחה (תט״ר) לנפגעי פעולות איבה — ביטוח לאומי.

## מה המחשבון עושה

חישוב תט״ר ב-8 שלבים:
1. **בדיקות סף** — הכרה כנפגע, תאריך אירוע, גיל
2. **נכות** — אחוזי נכות מוכרים וניכוי חודשי
3. **משפחה** — מצב משפחתי, ילדים וגילאיהם
4. **תעסוקה** — שכיר/עצמאי/לא עובד, נתוני שכר
5. **אי כושר** — תקופה והיקף
6. **אשפוז** — ימי אשפוז והפחתות
7. **גמלאות אחרות** — ניכוי גמלאות מגופים ממשלתיים
8. **תוצאה** — פירוט מלא עם סכום סופי
